# SDEV 355 Midterm — Campus Study Rooms

A starter Vite + React project for the midterm programming exercise. It gives you a working
dev server, the `public/rooms.json` dataset your app must fetch, a shell `src/App.jsx`, and
all of the CSS you will need in `src/index.css`.

## Getting started

```
npm install
npm run dev
```

Open the URL the dev server prints and confirm the page loads before you change anything.
The dataset is served at <http://localhost:5173/rooms.json>.

## Where your work goes

- `src/App.jsx` — marked with a comment
- `src/components/` — one component per file

Do not edit `public/rooms.json` or `src/index.css`. You will not need to write any CSS.

The exercise document handed out with this assessment is the source of truth for what to
build. If this README and the exercise document disagree, follow the exercise document.
